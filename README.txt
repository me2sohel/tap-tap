TAP-TAP HEART WEBSITE

How to use:
1. Open index.html in a modern browser.
2. Tap the small image icon in the upper-left corner and select your own photos.
3. Tap the glowing heart to cycle through your selected photos.
4. Use the sound icon in the upper-right corner to mute/unmute the heartbeat.

The photos are loaded locally in your browser and are not uploaded to a server.
Heartbeat sound is generated in the browser; no separate audio file is needed.

GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html (and optionally this README).
3. Open Settings > Pages.
4. Set deployment source to Deploy from a branch, choose main and /(root), then Save.
